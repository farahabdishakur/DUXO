Android

  1. Taabo Android oo soo deji.
  2. Fur faylka, oggolow “Install unknown apps”, kadib Install.
  3. Laga bilaabo v0.5 noocyada cusub waxay ku rakibmaan kuwa hore (xogtu way haraysaa). Haddii aad haysato v0.4 ama ka hor, hal mar tirtir.

Windows

  1. Soo deji, midig-guji → Extract All.
  2. Fur duxo.exe (ha kala saarin DLL-yada iyo galka data).
  3. “Windows protected your PC” → More info → Run anyway.

iPhone (bilaash, Sideloadly)

  1. PC-ga Windows: ku rakib iTunes iyo iCloud (ka soo deji apple.com, ha ka soo dejin Microsoft Store), kadib Sideloadly (sideloadly.io).
  2. Soo deji DUXO-v0.5.0-iPhone.ipa (badhanka iPhone ee kore) PC-ga.
  3. iPhone-ka USB ku xidh PC-ga, fur Sideloadly, ku jiid faylka IPA, geli Apple ID-gaaga, taabo Start.
  4. iPhone: Settings → General → VPN & Device Management → Apple ID-gaaga → Trust. iOS 16+: Settings → Privacy & Security → Developer Mode → shid.
  5. Apple ID bilaash ah: app-ku wuxuu shaqeeyaa 7 maalmood; kadib Sideloadly ku celi (xogtu way haraysaa).

Isku xidhka

  1. Shid Bluetooth (Android 10–11: shid Location sidoo kale).
  2. Dhow → Raadi dad kuu dhow → Ku dar. Qofka kale wuxuu taabanayaa Aqbal.
  3. Ama: Ku dar qof → Koodh, qor koodhka 6-da xaraf ee qofka (wuxuu ka helayaa Aniga).
